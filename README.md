## `01` — About this repository

Welcome to my Python learning workspace.

This repository documents my journey of learning Python through organized folders, hands-on coding, and practice programs. My focus is on understanding programming fundamentals instead of simply memorizing syntax.

I am building my foundation step by step and improving my code as I learn.

## `02` — Learning workspace

| Topic | What I am exploring |
|---|---|
| Basics | Core Python syntax and data types |
| Conditionals | Decision-making using conditions |
| Loops | Repeating operations and iteration |
| Functions | Reusable blocks of code |
| Data Structures | Working with Python collections |
| Exception Handling | Handling errors and exceptions |
| File Handling | Reading and writing files |
| OOPs | Object-oriented programming concepts |
